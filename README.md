
# 📱 Rotinapp

Aplicativo de **rotina pessoal** desenvolvido para ajudar o usuário a criar, organizar e acompanhar suas atividades de forma simples e prática.

## 🎯 Objetivo

O Rotinapp tem como objetivo facilitar a organização da rotina pessoal, permitindo que o usuário registre suas atividades, defina horários e acompanhe o que já foi realizado.

## ✨ Funcionalidades

* ✅ Criação de atividades
* ✏️ Edição de atividades
* 🗑️ Exclusão de atividades
* ☑️ Marcação de atividades como concluídas
* 🗂️ Organização por categorias
* ⏰ Definição de horários
* 🔄 Configuração de atividades recorrentes
* 📋 Visualização das atividades da rotina
* 🌤️ Consulta de clima e previsão do tempo
* 🔔 Notificações e configurações do aplicativo
* 🌙 Modo claro e escuro

### Categorias

As atividades podem ser organizadas em:

* 💼 Trabalho
* ❤️ Saúde
* 💡 Lazer
* 📋 Outros

## 🌦️ API de Clima

O aplicativo utiliza uma API de clima para obter informações sobre as condições meteorológicas.

Essas informações poderão ser utilizadas para identificar situações em que o clima possa interferir nas atividades planejadas.

## 🚀 Futuras Atualizações

O projeto possui algumas funcionalidades planejadas para versões futuras:

* ➕ Novos tipos de atividade
* 🏷️ Criação de categorias personalizadas pelo usuário
* 📅 Adaptação da rotina para festividades e feriados
* 👤 Avatares personalizados
* 🚗 Integração com informações de trânsito
* 📍 Integração com informações de localização
* 🔎 Identificação de outras possíveis interferências na rotina
